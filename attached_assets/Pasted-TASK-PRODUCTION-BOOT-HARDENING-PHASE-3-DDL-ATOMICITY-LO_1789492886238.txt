3. ADVISORY LOCK SAFETY
==================================================

Audit every startup DDL advisory lock.

Verify:

- lock acquisition and release use the SAME database session/client;
- pooled connections cannot cause unlock to execute on another session;
- exception paths release the lock;
- no connection is returned to the pool while still holding a session lock;
- nested callers cannot accidentally release another owner's lock;
- lock keys do not collide between unrelated owners.

Where unsafe, correct narrowly.

Do not replace this with a new distributed-lock architecture.
