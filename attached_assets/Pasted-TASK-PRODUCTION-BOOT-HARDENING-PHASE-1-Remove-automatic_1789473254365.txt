Independent audits found that normal production boot currently has two overlapping marketplace/demo content paths:

1. reconcileKnownTestListings()
2. seedProductionMarketplaceDemoContent()

The audits found that reconcileKnownTestListings() reaches ensureProductionDemoMarketplace() in production and can create managed marketplace demo content.

Then seedProductionMarketplaceDemoContent() runs afterward.

Both use the same managed marker:

[LUMERA_DEMO_MARKETPLACE_2026_08_25]

The first path can create approximately:
- 2 users
- 1 education center
- 1 course category
- 1 subscription plan
- 1 subscription
- 102 job listings
- 6 courses

The second seeder then sees a partial managed set and can log an error on every production boot.

This task is NOT permission to delete production data.
