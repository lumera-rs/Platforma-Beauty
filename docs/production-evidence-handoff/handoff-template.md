Before handoff, remove passwords, tokens, connection strings, private keys,
personal data and unnecessary internal identifiers. Use the approved secure
evidence channel, not this repository or chat. A reviewer must independently
verify source, target, scope, integrity and freshness. Attachment alone does not
change `NOT_COLLECTED`.
